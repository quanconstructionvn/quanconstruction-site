# SEO Automation Implementation Plan

Người tạo: Quang Mai Phú

**Goal:** Tự tạo trang tin, sitemap, triển khai Pages và hai trang dịch vụ.
**Architecture:** Python tạo thư mục _site từ repo; Actions kiểm thử trước khi deploy artifact. CMS JSON là nguồn, HTML cũ được bảo toàn.
**Tech Stack:** Python 3.12 stdlib, unittest, GitHub Actions/Pages.
**Spec:** docs/superpowers/specs/2026-11-10-seo-design.md

## Global Constraints
- Người tạo/chỉnh sửa: Quang Mai Phú.
- Không đổi main khi chuẩn bị; không đổi DNS; không cam kết thứ hạng.
- Không ghi ngược JSON hoặc HTML sinh ra vào repo trong workflow.

## Review Focus
- Tin cũ với link và body rỗng phải giữ nguyên.
- Slug trùng, đường dẫn vượt thư mục hoặc URL ngoài không được ghi nhầm file.
- Nội dung có HTML/script phải hiển thị dạng chữ an toàn.
- Sitemap loại noindex và các thư mục nội bộ; lastmod không thay vì chạy lại build.
- Tạo/xóa/sửa CMS phải phản ánh vào bản build, không tích lũy bài sinh ra cũ.
